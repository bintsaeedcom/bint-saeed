## Colour suffix codes

| Suffix | Colour |
|--------|--------|
| BLK | Black |
| BUR | Burgundy |
| NVY | Navy Blue |
| NVG | Navy Grey |
| DBR | Dark Brown |
| DMN | Dark Maroon |
| PPK | Peach Pink |
| MAG | Magenta |

Unknown colours derive a 3-letter code from the colour name.

Size, length (cm), and personalisation remain on the **order line** — not in the SKU.
