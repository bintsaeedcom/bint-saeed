# Scoring & allocation

## Fit score (0–100)

| Points | Criterion |
|--------|-----------|
| 0–25 | Audience overlap with contemporary fashion / culture / Gulf–global style |
| 0–20 | Reach or authority (masthead, byline weight, store calibre, subscriber base) |
| 0–20 | Evidence of covering heritage, craft, MENA, or elevated RTW |
| 0–15 | Clear contact path (email or form) |
| 0–10 | Language match (EN/AR/FR/IT/DE/ES preferred) |
| 0–10 | Timeliness (recent activity, open call, seasonal feature) |

- **Priority 1:** 75+  
- **Priority 2:** 55–74  
- **Priority 3:** research only / nurture  

Draft pitches only for Priority 1–2 unless user asks otherwise.

## Royal visit, UHNW, celebrity & screen boost

When public sources show royals, major UHNW cohorts, or A-list talent in **Abu Dhabi / UAE**, or when suitable screen productions are announced:

1. Open a mini-batch note in that day’s `SUMMARY.md` (`royal-visit` / `uhnw-private` / `celebrity-stylist` / `screen-costume`).
2. Research only **published** court, palace, embassy, household office, stylist, agent, or publicist contacts — never personal celebrity/royal emails/DMs.
3. Prefer warm paths: stylists, PAs, and protocol offices already in the ledger.
4. Draft partnership intros for peer brands only via **official** collab / cultural partnership routes.
5. Aspirational talent examples for stylist/management research: Madonna, Shakira, Rihanna, Georgina Rodríguez, Kim Kardashian, Jenner sisters, Gigi Hadid — always via published gatekeepers.
