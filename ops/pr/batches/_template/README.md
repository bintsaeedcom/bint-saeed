# PR batch — template

Copy this folder to `ops/pr/batches/YYYY-MM-DD/` when starting a day.

## Checklist

- [ ] ~50 prospects in `prospects.json`
- [ ] Vertical mix matches CHANNEL_MATRIX.md
- [ ] Region coverage noted in `SUMMARY.md`
- [ ] Priority 1–2 drafts in `drafts/`
- [ ] Queue updated: `ops/pr/queue/PENDING_APPROVAL.md`
- [ ] Ledger appended: `ops/pr/ledger/prospects.jsonl`
