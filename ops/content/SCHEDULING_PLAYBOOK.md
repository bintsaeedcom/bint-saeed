# Scheduling playbook — free tools only

Goal: draft in Cursor → approve → schedule/post with **native free** tools. No Buffer/Later paid plans required.

## 1. Prep (once per pack)

1. Approve copy in `ops/content/queue/`
2. Export images from your phone/Drive/Shopify/repo galleries  
3. Rename simply: `product-01.jpg`, `product-02.jpg`…  
4. For Reels: trim in **CapCut** (free) or Instagram native editor — real footage only

## 2. Instagram + Facebook — Meta Business Suite (free)

1. [business.facebook.com](https://business.facebook.com) → **Planner** / **Content**  
2. Create post → select IG (and FB only if you want)  
3. Paste approved caption from `IG.md`  
4. Schedule OR publish  
5. Stories: often easier in IG app same day (link sticker to PDP)

**Tips**

- Carousel: upload in the approved order from `ASSET_NOTES.md`  
- Keep one PDF/sheet of weekly slots from `WEEKLY_CALENDAR.md`

## 3. Pinterest (free)

1. Pinterest Business account  
2. Create Pin → title + description from `PINTEREST.md`  
3. Destination = product or collection URL  
4. Use **Schedule** when available (native)

Pin consistently — discovery compounds.

## 4. TikTok (free)

1. Draft in CapCut or TikTok  
2. Paste caption from `TIKTOK_REELS.md`  
3. Post when you can reply same day (algorithm prefers active accounts)  
4. Optional: reuse the same cut as IG Reel (re-export; don’t always crosspost watermarks)

## 5. YouTube Shorts (optional, free)

1. Upload same vertical video  
2. Title/description from `YOUTUBE_SHORTS.md`  
3. Link in description to shop URL

## 6. X / LinkedIn (free)

Paste from `X.md` / `LINKEDIN.md`. Schedule with native scheduling if your account has it; otherwise post manually on calendar days.

## 7. Email (free tiers)

Use whatever you already have (e.g. free tier of an ESP, or a simple BCC newsletter later). Copy from `EMAIL.md`. **Don’t** invent discount claims.

## 8. Weekly 20-minute ritual

| Minute | Action |
|--------|--------|
| 0–5 | Open calendar + pending queue |
| 5–12 | Schedule IG + Pinterest for the week |
| 12–18 | Film/trim one Reel if planned |
| 18–20 | Mark queue items `posted` + note best performer |

## What not to buy yet

- Paid social suites  
- AI video that redraws garments  
- Automated cross-post spam tools  

If one channel clearly drives traffic, deepen that channel before adding tools.
