# Content pack template

Follow `PLATFORM_RULES.md` and `ASSET_NAMING.md` strictly. **Never** paste one caption to every platform.

## SUMMARY.md

```md
# Pack: <product name>
- Date:
- Slug / URL:
- Claim sources: (files or URLs)
- Angles used:
- Languages: EN (default)
- Status: awaiting_approval
- Platform rules applied: yes
```

## ASSETS_RENAME.md

**Required.** Table of every image/video:

| # | Original | Renamed (`bint-saeed-…`) | Alt text |
|---|----------|--------------------------|----------|
| 1 | | | |

## ASSET_NOTES.md

- Colour / silhouette / setting observed (from real assets)
- Carousel / pin order using **renamed** filenames
- Video shot list from existing frames only

## ALT_TEXTS.md

Full alt list (can mirror rename table). One human, descriptive line per asset; include Bint Saeed once where natural.

## KEYWORDS.md

Follow `KEYWORD_TRENDS_AUDIT.md` fully (not a thin tag list).

Required sections:

1. **Google** — owned GSC (if pasted) + autocomplete/related + seasonality + max 5 safe phrases  
2. **Pinterest discovery** — suggested searches + 3–5 title seeds  
3. **TikTok discovery** — search suggestions + catchy title seeds + trend use/skip  
4. **Instagram discovery** — light hashtag/search notes + first-line hooks  
5. **Scored phrases** — A / B / C  
6. **Hashtag clusters** — by platform caps (see PLATFORM_RULES)  
7. **3 content-gap ideas** — suggestions only; no live SEO edits  

A/B phrases must appear **naturally** in Pinterest titles, TikTok title+description, and IG first lines — never stuffed.

## X.md

**Short only.** 2–3 posts:

- Body ≤ 200 chars preferred (max 280)  
- 0–1 hashtag  
- No long SEO description  

## IG.md

Per angle (2–3):

- Feed caption ~50–120 words (strong first line)  
- 8–12 hashtags  
- Carousel order (renamed files)  
- Stories overlays (very short)  
- Reference alts in `ALT_TEXTS.md`  

## PINTEREST.md

Per pin (2–4) — **not** an IG caption:

- Title ≤ 100 chars (keyword-aware, luxury-clean)  
- Description 2–4 sentences + URL  
- Board  
- Renamed vertical asset + alt  

## TIKTOK_REELS.md

Per video (1–2):

- **Title** (catchy, ≤ ~60 chars)  
- **Description** (long, ~150–400 words: story + product + CTA + URL)  
- On-screen text beats  
- Hook / timing sheet  
- 3–5 hashtags  
- Renamed video file  

## YOUTUBE_SHORTS.md

- 3 title options  
- Medium-long description + URL  
- Tags  

## LINKEDIN.md

- ~80–150 words house update  
- 0–3 hashtags  

## EMAIL.md

- Subject ×2, preview, short body + URL  

## CALENDAR_ROW.md

Suggested day + channel per asset (use renamed filenames).
