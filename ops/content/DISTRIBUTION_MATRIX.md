# High-value content distribution matrix

Goal: spend energy where organic discovery is real. Not “post everywhere equally.”

## Value ranking (Bint Saeed)

| Rank | Surface | Why | Content form |
|------|---------|-----|--------------|
| 1 | **Website / SEO** | Owns the customer; rankings compound | PDP quality, FAQs, editorial only when approved |
| 2 | **Pinterest** | Search + shop intent; long shelf life | SEO title + description + vertical pin |
| 3 | **Google via GSC-informed posts** | Captions/pins that mirror real queries | Use `_gsc` owned demand in titles |
| 4 | **TikTok / Reels search** | Growing search box; titles matter | Catchy title + long description |
| 5 | **Instagram feed + Stories** | Brand + remarketing, weaker keyword SEO | Medium caption, calm visuals |
| 6 | **YouTube Shorts** | Secondary reuse of Reels | Title + description from pack |
| 7 | **Email** | Highest intent of owned list | Rare, editorial, one product |
| 8 | **X / LinkedIn** | Reach/PR adjacency, low product SEO | Short / craft update |

Viral luck is **not** a lane. Durable organic is.

## Weekly energy split (default)

| Share of effort | Channel |
|-----------------|---------|
| 35% | Pinterest (4–7 pins) |
| 25% | IG feed + Stories (brand presence) |
| 20% | One strong Reel/TikTok (searchable title) |
| 10% | GSC-informed planning (which product/query to push) |
| 10% | X / LinkedIn / email / Shorts reuse |

## Automatic (Stage 1) vs later

### Stage 1 — now (this repo)

1. Drop GSC CSV → `ops/content/inbox/_gsc/`  
2. Content Pack reads it into **Owned demand**  
3. Drafts bias Pinterest + TikTok titles toward A-phrases  
4. You schedule with free native tools (`SCHEDULING_PLAYBOOK.md`)  
5. Review packs in `/admin/content`

### Stage 2 — connect platforms (later, not free-free)

Approve-first **push** via official APIs (Meta Graph, Pinterest, TikTok, YouTube).  
Needs developer apps, tokens, review, and per-platform policy.  
Still **human approve** before publish for luxury.

### Stage 3 — daily creative automation (later + budget)

Image/video generation from **your** product frames; never invent garments.  
Hard monthly cost caps. Creative Director = you (or scored review), never blind auto-post.

## “Completely automated” truth

Full hands-free across all platforms is a **product company roadmap**, not a weekend toggle.  
Best path that still protects the house:

**Automate research + drafting + rename/alts → human approve → (later) API schedule.**

Skipping approval to save time will eventually cost more in brand damage than it saves.
