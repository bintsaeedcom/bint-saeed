# Channel matrix — owned posting (free cadence)

Target: **steady publishing**, not every platform every day. Consistency wins.

## Weekly mix (default)

| Channel | Posts / week | Format focus | Notes |
|---------|--------------|--------------|-------|
| Instagram Feed | 2–3 | Product still · carousel detail · lifestyle | Meta Business Suite (free) |
| Instagram Stories | 3–5 | Behind process, poll, PDP swipe-up/link sticker | Same week as feed |
| Instagram / TikTok Reels | 1–2 | 7–20s: detail, drape, strand close-up | CapCut free templates OK |
| Pinterest | 4–7 | Vertical pins; SEO titles | Pinterest native scheduler |
| X | 2–3 | Short house notes / product lines | Native |
| LinkedIn | 0–1 | Craftsmanship / Abu Dhabi house (not hard sell) | Native |
| YouTube Shorts | 0–1 | Same reel re-export | Optional |
| Email | 0–1 | Soft launch or editorial | Esp. after a product push |

## Priority if time is short

1. **Pinterest** (evergreen discovery)  
2. **Instagram feed + Stories**  
3. **One Reel**  
4. Everything else

## Angle bank (rotate)

| Angle | Use when |
|-------|----------|
| `product-focus` | Clear PDP push |
| `craftsmanship` | Seams, lining, stone, hardware |
| `heritage-forward` | House Codes / Al Talli / Rosette — claim-safe |
| `city-dressing` | Travel / day-to-evening |
| `strands` | Signature Strand / charms |
| `gift` | Seasonal only — no fake scarcity |
| `styling` | Abaya + dress pairing already on site |

## Do not

- Post the same caption across all platforms unchanged
- Dump 30 hashtags on every IG post
- Schedule claims that aren’t on the website
