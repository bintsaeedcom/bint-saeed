# Keyword & trends audit (free)

Goal: raise **organic discovery** odds — Search, Pinterest, TikTok/Reels search, and IG discovery — without paid keyword tools.

This is **research for captions/titles**, not automatic live SEO edits (meta/schema need explicit approval).

## What ChatGPT meant (translated)

| Idea | Reality on $0 |
|------|----------------|
| Audit Google keywords | Yes — GSC (if you have access) + autocomplete + related searches |
| Trending on other platforms | Partial — each app’s **search suggestions** + public Trends; no perfect free “viral API” |
| Rank organically | Strongest on **Google** (site) + **Pinterest** + **TikTok search**; IG is weaker for keyword SEO |
| Go viral | Unpredictable; trendjacking helps *reach*, not guarantee sales. Stay on-brand |

**Priority for Bint Saeed:** Pinterest titles + TikTok title/description + on-site SEO pages (separate, approve-first) ≫ hashtag spam.

## Every Content Pack → expand `KEYWORDS.md`

### A. Google (search demand)

Do this with web search / browser (free):

1. **Autocomplete** — type product class + geo/modesty/luxury cues  
   Examples (adapt to product; only use claim-safe phrases):  
   `abaya abu dhabi`, `black abaya evening`, `natural stone necklace`, `phone charm luxury`
2. **People Also Ask / related searches** — list 5–10 phrases people actually type  
3. **GSC owned demand (highest priority)** — always check:
   - `ops/content/inbox/_gsc/LATEST_OWNED_DEMAND.md` if present
   - else raw `*.csv` in `ops/content/inbox/_gsc/`
   - else ask user to export (see that folder’s README)
   Put matching phrases first under **Owned demand (GSC)** in KEYWORDS.md
4. **Google Trends** (trends.google.com) — note interest over time for 2–3 seed terms (UAE + Worldwide if useful)

Output block:

```md
### Google
- Owned demand (GSC): …
- Autocomplete / related: …
- Seasonality note: …
- Safe phrases to weave (max 5 for this product): …
```

### B. Pinterest (high SEO value for shopping)

1. Open Pinterest search → type category + style words  
2. Note **suggested searches** and top pin **title patterns**  
3. Prefer descriptive titles: product type + colour/code/city — luxury tone, not spam

```md
### Pinterest discovery
- Suggested searches: …
- Title patterns that fit the house: …
- Pin title seeds (3–5): …
```

### C. TikTok (search + trend — carefully)

1. TikTok search bar suggestions for the product class  
2. Optional: Creative Center / trending sounds — **only if on-brand**; never force a meme voice onto luxury  
3. Separate **search keywords** (in title/description) from **for-you entertainment** hooks

```md
### TikTok discovery
- Search suggestions: …
- Catchy title seeds (search-friendly): …
- Trend note (use / skip + why): …
```

### D. Instagram (limited keyword SEO)

1. Search suggestions + related audio/hashtag counts only as weak signals  
2. Focus on **clear first line** + 8–12 mixed hashtags (brand + craft + 2–3 discovery)  
3. Do not chase viral audio that breaks house tone

```md
### Instagram discovery
- Hashtag / search notes: …
- First-line hooks that stay luxury: …
```

### E. X

Keyword SEO is weak. Prefer timely **short** lines; 0–1 tag. Skip trend spam.

## Scoring (pick what to use in copy)

For each candidate phrase, mark:

| Score | Meaning |
|-------|---------|
| A | Clear intent + on-brand + we can truthfully use it |
| B | Useful secondary |
| C | Skip (off-brand, competitive spam, invents a claim) |

**Only A/B phrases** may appear in titles/descriptions.

---

## How to use in platform copy

| Platform | Where keywords go |
|----------|-------------------|
| Pinterest | **Title** front-load + natural description |
| TikTok | **Title** + woven into **long description** |
| Instagram | First line + light body + restrained hashtags |
| X | Almost never “SEO”; clarity only |
| YouTube Shorts | Title + description tags |
| Site blog/PDP | Separate task — **user must approve** before any live SEO edit |

---

## Viral vs durable

- **Durable organic:** Pinterest + Google + TikTok search for evergreen products  
- **Spike / “viral”:** timing + hook + shares — treat as bonus, not the plan  
- Never sacrifice luxury voice for a trend that sounds like a generic fashion TikTok farm
