# Content pack template folder

Copy this folder to:

`ops/content/batches/YYYY-MM-DD/<product-or-theme-slug>/`

Then fill each file (or let the Content Pack skill create them).

Files to include:

- SUMMARY.md
- ASSETS_RENAME.md
- ALT_TEXTS.md
- ASSET_NOTES.md
- KEYWORDS.md
- X.md
- IG.md
- PINTEREST.md
- TIKTOK_REELS.md
- YOUTUBE_SHORTS.md
- LINKEDIN.md
- EMAIL.md
- CALENDAR_ROW.md

See also: `ops/content/PLATFORM_RULES.md`, `ops/content/ASSET_NAMING.md`
